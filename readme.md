# Film Green Book · Art Department Carbon Calculator

A single-file Streamlit web application for film and theatre art departments to estimate and reduce the carbon and water footprint of props and set materials.

## Deployment Guide (Streamlit Community Cloud)

1. Ensure your repository root contains **`app.py`** (lowercase), **`requirements.txt`**, and **`.streamlit/config.toml`**.
2. Go to [share.streamlit.io](https://share.streamlit.io/), select your repository, and set **Main file path** to `app.py`.
3. Click **Deploy**.
